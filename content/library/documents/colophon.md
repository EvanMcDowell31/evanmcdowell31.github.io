## Stack

- **Generator:** [Hugo](https://gohugo.io), a static site generator written in Go
- **Templates:** hand-written Go `html/template` with no theme
- **Hosting:** GitHub Pages, deployed by GitHub Actions on every push to `main`
- **Search:** a JSON index generated at build time and searched in the browser with a few lines of vanilla JavaScript

## Type and color

Headings are set in Fraunces and body text in Nunito. The palette is oat, parchment, terracotta, sage and moss, with a warm dark mode that follows your system setting.

## Principles

No trackers, no cookies and no framework. Content first, everything else gets out of the way.
